# ALIOUA BTP MANAGEMENT

نظام داخلي مستقل لإدارة الملاحظات والمهام والتقدم في مواقع البناء.
هذا المشروع ليس برنامج BIM ولا يتضمن نمذجة ثلاثية الأبعاد أو قراءة IFC في MVP.

## مكونات المستودع

- `backend/`: واجهة API باستخدام Python وDjango وDjango REST Framework.
- `web/`: واجهة الويب باستخدام React وVite.
- `mobile/`: تطبيق Flutter للهاتف.
- `docs/`: وثائق المعمارية والتشغيل والقرارات التقنية.

## الحالة الحالية

**الحالة الحالية — تأسيس المستودع ونماذج البيانات، مع بدء تأسيس API والمصادقة.**

تم إنشاء هيكل المستودع ونماذج Django، وأضيفت الآن نقاط فحص الخادم وتسجيل الدخول JWT وتجديد الرمز وبيانات المستخدم الحالي وتوثيق Swagger. واجهات CRUD وصلاحيات الأدوار التفصيلية وواجهتا الويب والموبايل ما زالت ضمن الأعمال القادمة.

## المتطلبات المجانية

- Python 3.11 أو أحدث متوافق مع إصدار Django الذي سيُثبت لاحقاً.
- Node.js إصدار LTS.
- Flutter SDK وAndroid SDK لبناء APK.
- Git.
- VS Code اختياري.

كل الأدوات البرمجية أعلاه مجانية ومفتوحة المصدر أو متاحة مجاناً. لا حاجة إلى بطاقة بنكية لهذه الأدوات.

## مبدأ التشغيل

المسار الأكثر ضماناً للمجانية هو تشغيل الخادم على حاسوب تملكه الشركة داخل شبكتها المحلية، مع نسخ احتياطي محلي منتظم. يمكن إتاحة الوصول عبر الإنترنت لاحقاً بعد اختبار مزود الاستضافة المجاني وحدوده.

**تنبيه:** SQLite مناسبة للتطوير والتجربة والاستخدام الداخلي البسيط. إذا زاد عدد المستخدمين المتزامنين أو حجم البيانات، نخطط للانتقال إلى PostgreSQL قبل التوسع. كما أن تخزين `media/` على خادم مجاني لا يعني بالضرورة أن الملفات ستبقى بعد إعادة تشغيل/إعادة إنشاء الخادم؛ يجب التحقق من وجود تخزين دائم قبل النشر.

## تشغيل المكونات

تعليمات Backend الأولية موجودة في `backend/README.md`. ما زال المشروع MVP قيد التطوير، ولا ينبغي استخدامه في الإنتاج قبل استكمال الصلاحيات والاختبارات والنسخ الاحتياطي.

## قواعد العمل

1. لا نربط هذا المشروع بتطبيق يونس أو Firebase.
2. لا نضيف خدمات مدفوعة أو خدمات تتطلب بطاقة بنكية.
3. لا نضيف وظائف خارج نطاق MVP دون موافقة.
4. لا ننتقل إلى المرحلة التالية قبل اختبار واعتماد المرحلة الحالية.
## تطبيق Android (Flutter)

مصدر تطبيق الموبايل موجود في `mobile/`. خطوات بناء APK عبر Flutter أو GitHub Actions موثقة في `mobile/ANDROID_BUILD_APK.md`. ملف ZIP المصدر ليس APK.
