# تطبيق Android — Flutter

## الوظائف الحالية
- تسجيل الدخول عبر JWT.
- إنشاء ملاحظة وتخزينها محلياً في SQLite حتى دون اتصال.
- التقاط صورة بالكاميرا والاحتفاظ بمسارها محلياً.
- محاولة مزامنة تلقائية عند عودة الاتصال، مع زر مزامنة يدوي.
- إرسال الملاحظة إلى API أولاً ثم رفع الصورة إلى endpoint الصور.
- الاحتفاظ بحالة pending/photo_pending عند فشل جزء من المزامنة وإعادة المحاولة لاحقاً.

## إعداد وتشغيل
يتطلب Flutter SDK وAndroid SDK (مجانيان ومفتوحا المصدر):
```bash
flutter create .
flutter pub get
flutter run --dart-define=API_BASE=http://192.168.x.x:8000/api
```
في شاشة الدخول داخل التطبيق، أدخل عنوان API الخاص بحاسوب الخادم مثل `http://192.168.1.10:8000/api`. يجب أن يكون الهاتف والحاسوب على شبكة Wi‑Fi نفسها. لا تستخدم 127.0.0.1 من الهاتف لأنه يشير إلى الهاتف نفسه.

## بناء APK
```bash
flutter build apk --release --dart-define=API_BASE=http://192.168.x.x:8000/api
```
الملف الناتج: `build/app/outputs/flutter-apk/app-release.apk`.

## ملاحظات قبل الاستخدام الفعلي
- أدخل UUID صحيحاً لمساحة موجودة في الخادم عند إنشاء الملاحظة.
- المزامنة تعتمد على صلاحية JWT؛ يجب تسجيل الدخول مجدداً عند انتهاء الرمز.
- إذا فشل إرسال الصورة بعد إنشاء الملاحظة، يحتفظ التطبيق بمعرّف الملاحظة ويعيد محاولة رفع الصورة دون إنشاء الملاحظة من جديد.
- يلزم اختبار فقد الاتصال المتكرر وتكرار الإرسال على أجهزة حقيقية قبل التوزيع على الفريق.

## الحصول على APK من GitHub Actions
عند نجاح سير العمل، افتح تبويب **Actions** في المستودع، ثم آخر تشغيل ناجح باسم **ALIOUA BTP checks**، واختر Artifact باسم `alioua-btp-android-apk`. مدة الاحتفاظ الحالية 30 يوماً. عند فتح التطبيق على الهاتف أدخل عنوان الخادم المحلي في خانة API قبل تسجيل الدخول.
