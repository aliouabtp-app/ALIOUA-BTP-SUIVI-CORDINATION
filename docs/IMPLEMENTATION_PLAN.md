# خطة التنفيذ — ALIOUA BTP

## قواعد التنفيذ
- العمل داخل هذا المستودع فقط.
- لا خدمات مدفوعة ولا خدمات تتطلب بطاقة بنكية.
- لا حذف أو استبدال قاعدة بيانات المستخدم أو ملفاته دون نسخة احتياطية وموافقة صريحة.
- كل مرحلة تنتهي باختبارات موثقة قبل الانتقال إلى التالية.
- لا نعلن عن ميزة على أنها جاهزة قبل تنفيذها والتحقق منها.

## المرحلة 2 — تثبيت Backend
- مراجعة Django models وmigrations.
- مراجعة إعدادات البيئة والأمان.
- استكمال CRUD للمشروع والمباني والطوابق والمساحات.
- استكمال Issues وTasks وPhotos وProgress وAuditLog.
- التحقق من الصلاحيات على مستوى الدور والمشروع.
- تشغيل الاختبارات وإصلاح أي فشل قبل الدمج.

## المرحلة 3 — API والتوثيق
- JWT: تسجيل الدخول وتجديد الرمز وبيانات المستخدم الحالي.
- CRUD مع البحث والتصفية والترقيم.
- رفع الصور والتحقق منها وضغطها.
- OpenAPI/Swagger واختبارات API.
- بيانات تجريبية آمنة لا تتضمن بيانات حقيقية.

## المرحلة 4 — Web
- تسجيل الدخول وإدارة الجلسة.
- لوحة التحكم والمؤشرات.
- شجرة المشروع وصفحات الطوابق والمساحات.
- إدارة الملاحظات والمهام والتقدم.
- مخططات الطوابق والتقارير.
- RTL عربي افتراضي وخيار الفرنسية وتصميم واضح عالي التباين.

## المرحلة 5 — Mobile
- تسجيل الدخول وقائمة الملاحظات.
- إنشاء ملاحظة والتقاط صورة.
- SQLite محلية وطابور عمليات pending.
- مزامنة آمنة عند عودة الشبكة ومعالجة التكرار والتعارض.
- بناء APK وتوزيعه مباشرة.

## المرحلة 6 — تكامل واختبارات
- اختبار صلاحيات الأدوار.
- اختبار رفع الملفات وأحجامها وأنواعها.
- اختبار Offline/Sync وفقد الاتصال والتكرار.
- اختبار التقارير والنسخ الاحتياطي والاستعادة.
- مراجعة الأمان قبل الاستخدام الفعلي.

## المرحلة 7 — التشغيل
- تشغيل محلي على شبكة الشركة.
- دليل نسخ احتياطي واستعادة.
- تقييم أي خطة استضافة مجانية حسب شروطها الحالية وحدودها، دون بطاقة بنكية أو دفع.
