# خطة التنفيذ وحالة النسخة — إتقان ALIOUA BTP

آخر تحديث: 25 نوفمبر 2026

## قواعد التنفيذ
- أدوات ومكتبات مفتوحة المصدر فقط، ولا خدمة مدفوعة أو بطاقة بنكية.
- عدم حذف قاعدة بيانات أو ملفات مستخدم قبل نسخة احتياطية وموافقة صريحة.
- لا تُعلن ميزة جاهزة قبل تنفيذها واجتياز اختبارات البناء المناسبة.
- التشغيل المحلي داخل شبكة الشركة هو الخيار الأكثر تحكماً؛ خطط الاستضافة المجانية تخضع لحدود المزود وقد تتغير.

## ما تم تنفيذه في المستودع

### Backend
- [x] نماذج المستخدمين والأدوار الخمسة والمشاريع والمباني والطوابق والمساحات.
- [x] الملاحظات والمهام والصور وسجلات التقدم وسجل التدقيق.
- [x] JWT وصلاحيات حسب الدور وإدارة المستخدمين للمدير.
- [x] Soft Delete وأرشفة للكيانات المدعومة.
- [x] ضغط الصور والتحقق من نوعها وحجمها.
- [x] مخططات PDF والصور ورموز QR للمساحات.
- [x] تقارير الملاحظات والمهام والتقدم بصيغتي PDF وExcel.
- [x] توليد GLB أولي من DXF محلياً، مع توثيق القيود.

### Web
- [x] تسجيل الدخول ولوحة المؤشرات والرسوم البيانية.
- [x] إدارة الملاحظات والمهام والمستخدمين.
- [x] إنشاء المشروع والمباني والطوابق والمساحات.
- [x] رفع مخططات PDF والصور وعرض الصفحة الأولى من PDF والصور.
- [x] وضع دبابيس الملاحظات على المخطط بإحداثيات نسبية.
- [x] متابعة التقدم حسب المساحة.
- [x] عرض نماذج GLB في Three.js.
- [x] تنزيل تقارير الملاحظات والمهام والتقدم.

### Mobile
- [x] تسجيل الدخول وتخزين JWT في التخزين الآمن.
- [x] قائمة الملاحظات وإنشاؤها مع صورة والتقاطها بالكاميرا.
- [x] حفظ الملاحظات والصور محلياً ثم مزامنتها.
- [x] عرض المهام وإنشاؤها وتعديلها محلياً ومزامنتها.
- [x] تخزين المساحات بعد أول اتصال ومسح QR.
- [x] بناء APK عبر GitHub Actions؛ يجب تنزيل artifact من تشغيل ناجح والتحقق من النسخة قبل التوزيع.

## ما لم يكتمل بعد — لا تعتبره جاهزاً
- [ ] الترجمة الفرنسية لجميع الشاشات والنصوص.
- [ ] عارض PDF متعدد الصفحات وحفظ رقم الصفحة مع كل دبوس.
- [ ] تحويل PDF وواجهات ومقاطع إلى هندسة 3D؛ المتاح حالياً DXF فقط.
- [ ] محرر 3D هندسي متقدم وأدوات تحرير العناصر.
- [ ] IFC عبر IfcOpenShell.
- [ ] عزل كامل للبيانات على مستوى المشروع ومراجعة الصلاحيات متعددة المشاريع.
- [ ] نسخ احتياطي تلقائي مع اختبار الاستعادة.
- [ ] اختبار ميداني شامل للمزامنة على أجهزة Android فعلية وحل التعارضات.
- [ ] إعداد إنتاج آمن (HTTPS، تخزين دائم، مراقبة، نسخ احتياطي).

## بوابات الاختبار قبل الاستخدام الفعلي
1. اجتياز اختبارات Django وبناء React وتحليل Flutter وبناء APK.
2. تجربة الأدوار الخمسة بحسابات مستقلة والتأكد من منع العمليات غير المصرح بها.
3. تجربة فقد الشبكة أثناء حفظ ملاحظة وصورة ومهمة ثم عودة الشبكة.
4. التأكد من عدم تكرار السجلات أو الصور عند إعادة المحاولة.
5. تجربة استعادة قاعدة البيانات ومجلد media من نسخة احتياطية.
6. اختبار عرض العربية في PDF على بيئة الخادم الفعلية.

## تعريف الجاهزية
اجتياز CI يثبت نجاح البناء والاختبارات الآلية المحددة فقط؛ ولا يثبت وحده صلاحية التطبيق للإنتاج أو سلامة بيانات الموقع أو صحة نموذج 3D هندسياً.
